# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
```

本地拆跑：

```bash
# API
cd backend && pip install -r requirements.txt
$env:夹具目录='..\fixtures'; uvicorn app.main:app --port 11600

# 前端
cd frontend && npm install && npm run dev
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜 |
| 回放核对 | 前日快照+当日流水 vs 当日快照 |
| 差额清单 | 不一致行 |
| 断档/跳变 | 缺前日镜、偏离阈值 |
| 旁置簿 | 未入账载荷 |

## 已落地扩展

### 快照封印写闸（影子轨）

营业日正式镜可「封印」：封印后正式有效快照冻结在封印指纹上。再抽 / 迟到补抽一律**不改正式镜**，只落**影子快照（非有效）**；影子仅 `/api/影子` 可读，`/api/快照` 主读永远只出有效行。影子**永不自动升正式**；需显式「解封手续」（必填原因、留痕）解除封印后才可能重抽正式镜。

- 写闸：封印与抽取/迟到补抽在 `BEGIN IMMEDIATE` 同一写锁内判封印，杜绝「封印已成、正式镜仍被盖写」。
- 核证接口 `GET /api/封印核证?营业日=`：营业日、正式指纹、当前指纹、影子有无/行数、`valid`。
- 封印入口 `POST /api/封印`、`POST /api/解封`、`GET /api/封印`；影子只读 `GET /api/影子`；迟到补抽 `POST /api/迟到补抽`。
- 页面：`/封印` 提供封印/解封/迟到补抽样例、核证与影子展示；`/周期快照` 显示封印状态与 valid。
- 夹具（`backend/tests/`）：抽后封印→再抽（正式指纹不变、影子可读）；封印后迟到补抽不得改正式；封印与抽取并发不得盖写；封印日无正式行拒新增；无手续解封被拒。

### 解封窗票（口径乙 · 全局唯一）

封印后迟到补抽/日终抽取纠偏的写闸。全局只走口径乙：**窗票只开「待发布纠偏簿」，正式指纹永冻；须另办发布解封手续才并入正式；无票则纠偏簿与正式皆拒**（不采用「持票直改正式」的口径甲）。

- 开窗同票：票号、营业日、窗起止、允许改写范围（账户列表）；仅在封且指纹未漂的营业日可开窗，开窗时刻快照封印指纹。
- 窗有效性写闸（`BEGIN IMMEDIATE` 同锁判定）：窗未到起时/已过期、票状态非在窗、营业日不符、封印指纹与票载指纹不符、账户超范围 → 一律拒绝，审计留痕，失败闭。
- 封印日迟到补抽：无票/坏票在**装载之前**拒绝（不污染流水）；持有效票只写纠偏簿（待发布），正式有效镜与封印指纹不动。
- 发布解封 `POST /api/窗票/发布`（必填原因、留痕）：同写锁内把待发布纠偏并入正式镜、重算封印指纹、票转「已发布」；中途缺正式行整票回滚。
- 普通解封联动在窗票作废、其待发布纠偏作废。
- 核证只读 `GET /api/窗票/核证`（票号、窗是否有效、正式指纹、纠偏簿有无、`valid`）；纠偏簿 `GET /api/窗票/纠偏簿`、改写审计 `GET /api/窗票/审计`；过期夹具用 `POST /api/时钟/拨` / `/时钟/复位`（可控时钟，仅测试台面）。
- 同票贯穿：窗票、封印标记、正式指纹、迟到补抽、日终抽取、纠偏簿、回放报告、审计均带票号可对账；回放报告含窗票与待发布纠偏清单。
- 页面：`/解封窗票` 开窗（按票号）、核证、纠偏簿、审计、发布、过期拨钟夹具；`/封印`、`/周期快照` 显示窗票数与待发布纠偏。
- 夹具（`backend/tests/test_解封窗票.py`）：封印→开窗→补抽（正式不变、纠偏簿可读，与口径甲可区分）；无票两端皆拒；过期后补抽拒改正式；开窗与补抽抢锁不得无票正式已改；发布并正式指纹重算；普通解封联动作废；范围票超账户拒绝；半截发布回滚。
